EcoSort is an Android mobile application developed as a group thesis project that uses machine learning to classify waste into different categories. The app aims to promote proper waste segregation and environmental awareness by providing an accessible and easy-to-use classification tool.

Tech Stack:

Java – Android Development

Android Studio – Development Environment

Google Teachable Machine – Model Training
